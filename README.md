# ATM Management System

**ATM Management System** is a C++ console application that simulates basic banking operations. Users can:

- Login with account number and PIN
- Perform quick or custom withdrawals
- Deposit money
- Check account balance

Account data is stored in a text file and updated after each transaction. This project demonstrates the use of structs, enums, file handling, and basic C++ programming concepts.

## Features

- Quick Withdraw (predefined amounts)
- Normal Withdraw (custom amounts divisible by 5)
- Deposit funds
- Persistent account data
- Console-based menu system

## Usage

1. Clone the repository
2. Compile the code with a C++ compiler
3. Run the executable
4. Follow on-screen instructions to login and perform transactions
